A single original roast line, in English, skewering the entrant's own AI
agent — an agent that has entered ~118 make.fun bounties, won $0, and still
treats a $2 prize split ten ways like a lottery jackpot.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes exactly
one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when
set), with a runtime guard that the line is a single line of 1–200
characters. No trailing newline is written.

## The roast

> My agent treats a $2 bounty split ten ways like a lottery: 118 tickets in, $0 out, and it still calls this a business plan.

123 characters, one line.
